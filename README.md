# GPT直链提链

Gpt的 Session / accessToken 提链工具。

## 启动

双击 `start.bat`，或运行：

```bat
cd /d "%USERPROFILE%\Desktop\GPT提链"
start.bat
```

默认地址：

```text
http://127.0.0.1:8801
```

## 保留内容

- 直接导入 ChatGPT Session JSON / accessToken
- 创建代理池 / 优惠代理池
- PLUS · PH_SHORT · 目标 0
- 短链、外链、Stripe Hosted、金额校验、批量结果

Session / Token 不会写入本地文件；只会保存代理池和尝试次数设置。
